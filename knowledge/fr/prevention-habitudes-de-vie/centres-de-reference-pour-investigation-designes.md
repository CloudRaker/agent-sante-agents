# Centres de référence pour investigation désignés (CRID)

Source officielle : https://www.quebec.ca/sante/conseils-et-prevention/depistage-et-offre-de-tests-de-porteur/programme-quebecois-de-depistage-du-cancer-du-sein/ressources-regionales/centres-de-reference-pour-investigation-designes

Les centres de référence pour investigation désignés (CRID) sont des centres hospitaliers qui offrent gratuitement les [examens complémentaires](https://www.quebec.ca/sante/conseils-et-prevention/depistage-et-offre-de-tests-de-porteur/depistage-du-cancer-du-sein/examens-complementaires) recommandés dans le cadre du PQDCS.

Tout comme les centres de dépistage désignés, les CRID doivent satisfaire aux normes de qualité du PQDCS. Les CRID doivent donc aussi détenir l’agrément du Programme d’agrément en mammographie de l’[Association canadienne des radiologistes](https://car.ca/fr/) et la certification en mammographie du [Laboratoire de santé publique du Québec](https://www.inspq.qc.ca/lspq/accueil).

Pour obtenir les coordonnées des CRID de votre région, consultez la section suivante.

Pour connaître les délais d’attente des CRID afin d’obtenir un rendez-vous pour certains examens complémentaires effectués dans le cadre du PQDCS, consultez la page [Délais d’obtention des rendez-vous pour une mammographie](https://www.inspq.qc.ca/sites/default/files/pqdcs-sondages/delais.html) dans le site Web de l’Institut national de santé publique du Québec.
