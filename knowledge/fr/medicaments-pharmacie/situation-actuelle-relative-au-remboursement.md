# Situation actuelle relative au remboursement des médicaments biosimilaires

Source officielle : https://www.quebec.ca/sante/medicaments/medicaments-biosimilaires/situation-actuelle-relative-au-remboursement

Voici quelques exemples de règles de remboursement des médicaments biosimilaires.

Pour de plus d'informations, consulter la page [Connaître les conditions de couverture du régime](https://www.ramq.gouv.qc.ca/fr/citoyens/assurance-medicaments/connaitre-conditions-couverture-regime) du site Internet de la Régie de l'assurance maladie.

## Dermatologie

Source officielle : https://www.quebec.ca/sante/medicaments/medicaments-biosimilaires/situation-actuelle-relative-au-remboursement

Les médicaments biosimilaires sont disponibles au Canada depuis 2014.

- Depuis 2020, tous les patients couverts par la RAMQ qui commencent un nouveau traitement reçoivent obligatoirement un médicament biosimilaire pour :
    - l’infliximab, dont le produit de référence est RemicadeMD;
    - l’étanercept, dont le produit de référence est l’EnbrelMD.
- Depuis mars 2021, un nouveau médicament biosimilaire est disponible pour l’adalimumab et les patients qui doivent commencer un traitement reçoivent ce médicament biosimilaire dont le produit de référence est HumiraMD.

## Endocrinologie

Source officielle : https://www.quebec.ca/sante/medicaments/medicaments-biosimilaires/situation-actuelle-relative-au-remboursement

Les médicaments biosimilaires sont disponibles au Canada depuis 2015.

- Depuis 2017, tous les patients couverts par la RAMQ qui commencent un nouveau traitement reçoivent obligatoirement un médicament biosimilaire pour l’insuline glargine, dont le produit de référence est LantusMD.
- Depuis mars 2021, un nouveau médicament biosimilaire est disponible pour l’insuline lispro. Les patients qui commencent un traitement reçoivent ce médicament biosimilaire dont le produit de référence est HumalogMD.
- Depuis septembre 2021, un nouveau médicament biosimilaire est disponible pour la prévention de l’ostéoporose, le tériparatide. Les patients qui commencent un traitement reçoivent ce médicament biosimilaire dont le produit de référence est FortéoMD.
- Depuis février 2022, un nouveau médicament biosimilaire est disponible pour l'insuline asparte. Les patients qui commencent un traitement reçoivent ce médicament biosimilaire dont le produit de référence est NovoRapidMD.

## Gastro-entérologie

Source officielle : https://www.quebec.ca/sante/medicaments/medicaments-biosimilaires/situation-actuelle-relative-au-remboursement

- Depuis 2020, tous les patients couverts par la RAMQ qui commencent un nouveau traitement reçoivent obligatoirement un médicament biosimilaire pour l’infliximab dont le produit de référence est le RemicadeMD.
- Le médicament biosimilaire adalimumab dont le médicament de référence est l’HumiraMD, est aussi disponible depuis mars 2021 et les patients couverts par la RAMQ qui commencent un traitement le reçoivent maintenant.

## Hématologie

Source officielle : https://www.quebec.ca/sante/medicaments/medicaments-biosimilaires/situation-actuelle-relative-au-remboursement

Les médicaments biosimilaires sont disponibles au Canada depuis 2021.

- Depuis 2021, tous les patients qui commencent un nouveau traitement pour l’enoxaparine reçoivent obligatoirement un médicament biosimilaire, dont le produit de référence est le LovenoxMD.

## Oncologie

Source officielle : https://www.quebec.ca/sante/medicaments/medicaments-biosimilaires/situation-actuelle-relative-au-remboursement

Les médicaments biosimilaires sont disponibles au Canada depuis 2019.

- Depuis 2019, tous les patients traités dans les centres d’oncologie du Québec qui commencent un nouveau traitement reçoivent obligatoirement un médicament biosimilaire pour le bevacizumab, dont le produit de référence est l’AvastinMD.
- Depuis 2020, un nouveau médicament biosimilaire est disponible pour le trastuzumab et les patients qui doivent commencer un traitement reçoivent ce médicament biosimilaire dont le produit de référence est l’HerceptinMD.

## Neurologie

Source officielle : https://www.quebec.ca/sante/medicaments/medicaments-biosimilaires/situation-actuelle-relative-au-remboursement

Depuis 2018, tous les patients atteints de sclérose en plaques qui commencent un nouveau traitement reçoivent le glatiramère dont le produit de référence est le CopaxoneMD. Il faut noter que le glatiramère n’est pas considéré au sens précis du terme comme médicament biosimilaire, mais bien comme un médicament complexe non biologique ultérieur.

## Rhumatologie

Source officielle : https://www.quebec.ca/sante/medicaments/medicaments-biosimilaires/situation-actuelle-relative-au-remboursement

Les biosimilaires sont disponibles au Canada depuis 2016.

- Depuis 2020, tous les patients couverts par la RAMQ qui commencent un nouveau traitement reçoivent obligatoirement un médicament biosimilaire pour l’étanercept, dont le produit de référence est l’ EnbrelMD.
- Depuis 2020, tous les patients couverts par la RAMQ qui commencent un nouveau traitement reçoivent obligatoirement un médicament biosimilaire pour l’infliximab dont le produit de référence est le RemicadeMD.

- Depuis mars 2021, un nouveau médicament biosimilaire est disponible pour l’adalimumab. Les patients qui doivent commencer un traitement reçoivent ce médicament biosimilaire dont le produit de référence est HumiraMD.
